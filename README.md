# Gemini for Windows Phone 8.1

Gemini, the AI assistant made by Google, now on Windows Phone! 

This app brings some of the capabilities of this powerful AI assistant to Windows Phone, it feels like 2014 again but better!

# Features:
-Choose the Gemini model used for responses. (Default model: gemini-3.1-flash-lite)\
-Maintain separate conversations with saved history.\
-Use conversation memory to retain key information from earlier messages.\
-Render Gemini responses with basic Markdown formatting, including headings, lists, quotes, and code blocks.\
-Switch the app language between English and Spanish.

# How to use it:
Use your Gemini API key (If you don't know how to get one, follow these instructions)

-Go to https://aistudio.google.com\
-Press the "Get Started" button and log in with your Google account.\
-Look for the key icon on the bottom left that says "Get API Key"\
-Create a new API key if you don't have one already.\
-Copy the API key and paste it into the Gemini app.\

REMEMBER NOT TO SHARE YOUR API KEY WITH ANYONE
